# The Mechanism

The Mechanism is a research cluster built from found infrastructure: an existing desktop and a
disused Raspberry Pi cluster, with a few pieces added where those ran out. It began as an exercise
in critical technical practice. The aim was to learn the affordances, constraints and possibilities
of AI for humanities and social science research by building with it, not renting it.

It is now the experimental platform for my next monograph, *Infrastructural Inflections: Critical
Technical Practice and the Architecture of Knowledge*. It also supports ongoing work related to my
current monograph, *Digital Modernity: Why We Need to Think Historically About the Digital Age*
(2026).

This site documents it at a technical level: what it is, how it works, what it costs, and what
building it has taught.
